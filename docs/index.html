¿Qué es y para qué sirve?

El conector BigQuery permite que el agente de Ruvic consulte datos almacenados en Google BigQuery — ejecutar consultas SQL, explorar qué datasets y tablas existen, y estimar el costo de una consulta antes de correrla.

Una vez configurado, puedes pedirle al agente cosas como:

  • "¿Cuáles fueron las ventas totales del mes pasado?"
  • "¿Qué tablas hay en el dataset de marketing?"
  • "¿Cuánto costaría esta consulta antes de correrla?"

Operaciones soportadas:

OperaciónQué hace
cloud.execute_queryEjecuta una consulta SQL y retorna los resultados
cloud.list_datasets_and_tablesLista los datasets del proyecto, o las tablas de un dataset
cloud.estimate_query_costEstima cuántos datos escanearía una consulta y su costo aproximado, sin ejecutarla
Protecciones de seguridad incorporadas Por defecto, este conector bloquea consultas de escritura (INSERT/UPDATE/DELETE/DROP/etc.) — solo consulta datos, no los modifica. También aplica un tope de bytes facturables por consulta, para evitar sorpresas de costo por una consulta mal escrita.

Prerrequisitos

  • Un proyecto de Google Cloud con la API de BigQuery habilitada.
  • Acceso a Google Cloud Console (IAM & Admin) para crear una cuenta de servicio.
  • Saber qué datasets/tablas necesita consultar el agente, para acotar los permisos al mínimo necesario.

Configuración en el fabricante

  1. Ve a Google Cloud Console.

    Abre console.cloud.google.com y selecciona el proyecto donde vive tu BigQuery.

  2. Crea una cuenta de servicio dedicada.

    Ve a "IAM & Admin" → "Service Accounts" → "Create Service Account". Ponle un nombre descriptivo, ej. "ruvic-bigquery-connector".

  3. Otorga los roles mínimos necesarios.

    En el paso de permisos, agrega los roles "BigQuery Data Viewer" y "BigQuery Job User". Solo agrega "BigQuery Data Editor" si vas a permitir consultas de escritura.

  4. Genera y descarga la clave JSON.

    En la cuenta de servicio recién creada, ve a la pestaña "Keys" → "Add Key" → "Create new key" → tipo JSON. Se descarga automáticamente un archivo — este es el que vas a pegar en el formulario de Ruvic.

Riesgo de seguridad El archivo JSON de la cuenta de servicio otorga acceso con los permisos que le diste — trátalo como una contraseña. No lo compartas por canales inseguros ni lo subas a repositorios de código.

Permisos requeridos

Rol de IAMPara qué lo usa el conector
BigQuery Data ViewerNecesario para execute_query, list_datasets_and_tables, estimate_query_cost
BigQuery Job UserNecesario para ejecutar cualquier consulta (correr el job en BigQuery)
BigQuery Data EditorSolo necesario si activas "Permitir consultas de escritura"

No otorgues el rol "BigQuery Admin" ni roles a nivel de organización — acótalo al proyecto o los datasets específicos.

Configuración en Ruvic

Entra a Settings → Conectores, busca la tarjeta BigQuery y pulsa Configurar.

Completa el ID del proyecto y pega el contenido completo de la clave JSON de la cuenta de servicio. Deja los campos avanzados (ubicación, tope de bytes facturables) en sus valores por defecto salvo que sepas que los necesitas ajustar.

Guarda y pulsa Probar conexión.

Verificación

  1. Test de conexión exitoso.

    El botón Probar conexión debe responder: "Conexión exitosa al proyecto [tu proyecto]".

  2. Prueba mínima con el agente.

    Pide algo de solo lectura primero:

    "¿Qué datasets hay en el proyecto?"

Solución de problemas

Mensaje / síntomaCausa probable y solución
"No se pudo interpretar la cuenta de servicio..."El JSON pegado está incompleto o mal copiado — vuelve a copiar el archivo completo, incluyendo las llaves de apertura y cierre.
"Permisos insuficientes..."A la cuenta de servicio le falta el rol "BigQuery Data Viewer" o "BigQuery Job User" sobre el proyecto/dataset.
"La consulta... supera el tope de bytes facturables"La consulta escanearía más datos que el límite configurado — agrega filtros para reducir el volumen, o aumenta "Tope de bytes facturables" si el costo es esperado.
"Consulta bloqueada: contiene la palabra clave de escritura..."Intentaste una consulta INSERT/UPDATE/DELETE/etc. con el modo de solo lectura activo (el default) — actívalo explícitamente si necesitas permitir escrituras.

Preguntas frecuentes y notas de seguridad

¿El agente puede modificar o borrar mis datos?

No, por defecto. El conector bloquea automáticamente cualquier consulta de escritura salvo que se active explícitamente esa opción.

¿La estimación de costo es exacta?

Es una aproximación basada en el precio de referencia estándar de BigQuery. Si tu proyecto usa un modelo de precio distinto (por capacidad, con descuentos), el costo real puede diferir.

¿Dónde queda guardada la clave de la cuenta de servicio?

Como secreto en el almacén de credenciales de la plataforma. La interfaz nunca vuelve a mostrarla.

¿Qué hago si la clave se compromete?

Ve a Google Cloud Console → IAM & Admin → Service Accounts, revoca/elimina la clave comprometida, genera una nueva, y actualízala en el formulario del conector.

Buenas prácticas Usa una cuenta de servicio dedicada y acotada al mínimo necesario; no otorgues "BigQuery Admin"; deja el bloqueo de escrituras activado salvo necesidad real; y ajusta el tope de bytes facturables según el tamaño esperado de las consultas.
